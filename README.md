# Protocolo: Brecha

Un videojuego narrativo y romántico construido en Python con Pygame. 
El juego consta de dos actos con temática dual (Navidad y Cyberpunk/Hacking) e incluye un sistema de guardado, fases de acción/habilidad, logros ocultos y una propuesta final integrada.

## Requisitos
- Python 3.8 o superior
- Pygame 2.5+

## Instalación
1. Clona o descarga el repositorio.
2. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecuta el juego:
   ```bash
   python main.py
   ```

## Controles Generales
- **Movimiento**: Teclas W, A, S, D o Flechas direccionales.
- **Acción**: Barra Espaciadora (Hackear, Disparar, Avanzar textos).
- **Pausa**: Tecla ESCAPE.

## Resetear Progreso
Para comenzar desde el principio, abre el juego, ingresa al menú de Configuración y selecciona "RESETEAR PROGRESO". Esto creará un backup y reiniciará tu partida.
